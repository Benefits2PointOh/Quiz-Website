# Quiz Website

A browser-based multiple-choice quiz game that evaluates answers and tracks the player’s score.

## Features

- Presents quiz questions in the browser
- Validates answers during play
- Tracks the number of correct answers
- Uses a responsive static front-end

## Technology

- HTML5
- CSS3
- JavaScript

## Run locally

Clone the repository and open `index.html` in a browser. No build step or server is required for the basic version.

```bash
git clone https://github.com/Benefits2PointOh/Quiz-Website.git
cd Quiz-Website
```

For local development, serve the directory with any static web server if your browser restricts local file access.

## Status

A completed learning project suitable for demonstrating fundamental browser scripting, DOM interaction, and front-end styling.
